# Gicho 0.0.9 checkpoint

This source checkpoint is the generic Gicho foundation for planning a CMS
consumer. CMS and Authackage have not been changed or tested against this tag.
The app chooses its own routes, data, copy, brand assets and authorized scope.

## Available now

- `GichoBootstrap` loads configuration and handles splash, failure and Retry.
- `GichoConfigurationService.loadApplication()` merges package defaults,
  optional app YAML/schema and explicit overrides under versioned validation.
- `GichoBrand` resolves app name, full logo and compact mark. A missing image
  uses the built-in symbol. The shared shell and modal app bars can show or hide
  the mark for each page.
- `GichoMaterialApp` composes app locale and theme choices. Gicho owns the
  20-locale registry, its own translated copy and English minimum.
- Default, Ocean and Ember are permanent theme choices with light/dark variants.
  A consumer selects its offered subset/default; the shared picker remembers a
  user's theme and system/light/dark choice on this device.
- `GichoAppShell` supplies the current drawer/sidebar page frame, while
  `GichoModalPage` supplies a full-page guided task frame. Consumers may use
  a custom shell or MaterialApp.

Footer destination back-stack mechanics remain on [Gicho #31](https://github.com/mozrin/gicho/issues/31).
The owner-defined rule is that switching footer destinations resets the stack
being left; app-bar and drawer movements preserve it. Current CMS has one main
screen, so that work does not block using this checkpoint to plan CMS. Authackage
brand adoption and Harmony pinning belong to their own tracked issues.

## Verification boundary

Package and focused example analysis/tests are the host verification gate for
this source checkpoint. Host widget tests cover phone, tablet and large widths.
A headless Linux run launched the bootstrap example, but its Xvfb screenshot
captured a black graphics surface, so rendered Linux appearance was not
visually accepted. Installed Android use and Harmony regressions belong to
their respective consumer integration gates. The new theme picker translations
need native-speaker review before production-quality claims.
