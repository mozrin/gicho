# Gicho examples

Runnable applications demonstrating the `moztopia` Flutter package.

Applications:

- [`example.minimal/`](example.minimal/README.md) shows the absolute-minimum
  simple-mode adoption with a consumer-owned page layout.
- [`example.everything/`](example.everything/README.md) demonstrates the
  complete integration.

```shell
cd example.everything
flutter pub get
flutter run
```

Both examples resolve the package from the sibling `../gicho` repository.
