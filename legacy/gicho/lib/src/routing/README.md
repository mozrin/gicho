# Routing

Gicho standardizes GoRouter through `GichoRouter` and exposes the
compatible GoRouter API through its public Flutter entry point:

```dart
import 'package:moztopia/gicho.dart';
```

Define and use routes with the go_router API directly:

```dart
final router = GichoRouter(
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const HomePage(),
    ),
  ],
);

GichoMaterialApp.router(router: router);
```

The package supports URL routing, deep links, redirects, nested navigation,
shell routes, and type-safe routes. Keep application route definitions in the
application. Advanced consumers can use `router.goRouter` to reach the
underlying compatible GoRouter instance.

Barrel files are generated by the barrel workflow utility and must not be
edited manually.

## Configuration reference

Routing currently has no Gicho YAML parameters and no `routing.config.yaml`.
Routes, redirects, deep-link handling, refresh behavior, observers, and error
pages remain Dart-owned. Adding `assets/gicho/routing.config.yaml` has no
effect.
