# GichoBrandImage

Shows a resolved full logo or compact mark from `GichoBrand`. The default
presentation uses the full logo; `compact: true` uses the mark. If the chosen
asset cannot load, it displays the built-in brand symbol (and name in full
mode). Use the compact form in app bars; use the full form in sign-in, startup
and other large identity surfaces. The compact image is constrained to 32 × 32
logical pixels so app-bar actions and large text cannot squeeze the mark out.
The widget carries an accessible label.
