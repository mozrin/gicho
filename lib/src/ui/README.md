# UI building blocks

Reusable visual constructs that do not own an entire application or feature
belong here. Import their supported APIs from `package:gicho/gicho.dart`.

- [Brand header](brand_header/README.md) presents a supplied name and logo.
- [Distance slider](distance_slider/README.md) selects a controlled distance.
- [Place lookup](place_lookup/README.md) searches real places and selects a position on a Google map.
- [Structured postal address fields](structured_postal_address_fields/README.md) render country-specific contact field definitions.
- [Contact phone field](contact_phone_field/README.md) renders a country choice and owner-declared phone capabilities.
- [Contact email field](contact_email_field/README.md) renders email entry and confirmed verification state.
