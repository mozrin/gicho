# Features

A feature may own UI, state and feature-specific logic. Reusable UI building
blocks and pure services live in their own source groups. Every feature has a
quick start and a deliberate public entry.

- [Localization](localization/README.md) owns locale selection and lookup.
- [Themes](themes/README.md) builds Flutter themes from app choices.
- [Scanner](scanner/README.md) captures app-configured QR and barcode values.
