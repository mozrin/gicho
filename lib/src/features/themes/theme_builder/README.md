# Theme builder

```dart
final theme = gichoTheme(seedColor: const Color(0xFF17634F));
```

Builds a generic Material 3 theme from a consumer-owned seed color and
brightness. Shared buttons keep a touch-friendly minimum height. Text-field
focus changes the existing underline color without adding a second outline or
changing its width. Apps select their own brand seed; Gicho carries no
Harmony palette or product policy.
